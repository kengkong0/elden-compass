# 艾尔登法环·褪色者探索罗盘 (Elden Compass)
> 专为 PC 端《艾尔登法环》量身定制的游戏内沉浸式置顶悬浮攻略 & 全收集防断罗盘

---

## 🌟 重构核心特性

1. **正常桌面程序化（彻底告别 CMD 控制台黑框）**
   - **`启动罗盘.pyw`**：双击即开，纯后台静默运行，完全没有黑框控制台！
   - **`start.bat`**：一键脚本已升级为后台瞬发启动，启动后 CMD 窗口秒关。
   - **系统托盘常驻 (System Tray)**：任务栏右下角常驻专属法环金色符文图标，支持右键一键显隐、切换穿透、翻页及安全退出。

2. **游戏内全局快捷键 (无需切出游戏)**
   - **`[Alt + M]` 或 `[F8]`**：瞬间 **显示 / 隐藏** 罗盘（Boss 战一键隐匿，战后一键呼出）。
   - **`[Alt + Q]`**：开启 / 解除 **「鼠标穿透模式」**（开启后鼠标直接点击操作游戏角色与视角，完全防误触）。
   - **`[Alt + ←]`**：直接翻看 **上一节** 攻略（游戏焦点中直接响应）。
   - **`[Alt + →]`**：直接翻看 **下一节** 攻略（游戏焦点中直接响应）。

3. **彻底根治文字遮盖与拥挤错乱**
   - **双层黑金导航架构**：将窗口拖拽区、控制按钮与功能 Tab 严格分层分栏，杜绝文字折行挤压。
   - **全宽沉浸式阅读 + 悬浮抽屉目录**：正文独占 100% 宽度，点击目录按钮平滑滑出 199 篇章节索引，选章即闭，宽敞舒适。
   - **BeautifulSoup 精准清洗**：彻底解决旧版正则表达式漏删闭合标签导致的文字层叠溢出 Bug。

4. **极速秒开与智能防卡死**
   - **Waitress 多线程高并发**：消灭单线程请求排队与假死现象。
   - **智能后台预加载 (Prefetch)**：当前阅读第 $N$ 节时，后台自动静默拉取并缓存 $N+1, N+2, N-1$ 节，翻页 **0 毫秒秒开**！
   - **缩略图优先加载**：正文图文采用轻量缩略图排版，点击任意图片即可通过无损灯箱放大查看全分辨率大图。
   - **滑块防抖与双重透明度修复**：拖动透明度滑块仅调用 Win32 接口，杜绝高频写盘与 CPU 占用卡死。

5. **全收集 & 关键支线防断追踪器 (Checklist)**
   - 🍷 **圣杯露滴** (12个全部位点)
   - 🌰 **黄金种子** (40个关键点)
   - 🎒 **护符皮袋** (3个)
   - 🔮 **记忆石** (8个)
   - 👑 **不可逆核心支线任务树**（魔女菈妮、死眠菲雅、战士壶亚历山大、米莉森纯净金针），打勾自动保存本地。

6. **开荒避坑与各区域推荐等级表**
   - 各大区域推荐等级与武器强化等级表（防止误入高等级区域受苦）。
   - 前期逃课神器速拿指引（猎犬长牙、陨石杖+岩石球、名刀月隐、乌龟盾等）。
